# Nima Soltani — Academic Site

Personal academic website for [nimasol42.github.io](https://nimasol42.github.io).

## Stack

Static HTML, CSS, and JavaScript. Hosted with GitHub Pages from the `main` branch.

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
npx --yes serve .
```

## Update content

Edit `index.html` for profile text, publications, teaching, and contact details. Replace `assets/portrait.jpg` or `assets/CV-Nima-Soltani.pdf` as needed.
